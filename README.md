A one-line 1-star review written by a houseplant about its human owner, for make.fun's "One Star, Written in Sap" bounty. The plant was moved to a "sunny spot" above the radiator and now drips sap on its owner's laptop — which it calls rent.

## Run it

```sh
npx tsx main.ts
```

This writes the review to `/output/entry.txt`.
